### Para quién

El panel se hizo para un fabricante multinacional.

### Cómo funciona

Automatizar una prueba es que el sistema conduzca su ejecución. Es en el panel, una aplicación web, donde se automatizan y gestionan las pruebas.

### La tecnología, en palabras simples

- **Python**: lenguaje de programación de uso general, fácil de leer y muy usado en automatización, análisis de datos y sistemas web; en el proyecto, es el lenguaje en que se escribió el panel.
- **Django**: framework web escrito en Python, que ya trae partes comunes de un sistema web, como acceso a base de datos y área administrativa; fue la base del panel.
