### Para quién

El panel se hizo para un fabricante multinacional y para quienes se encargan de las pruebas de validación de su línea de producción: las personas responsables de automatizar y gestionar esas pruebas.

### Cómo funciona

En la línea de producción del fabricante se hacen múltiples pruebas de validación. El panel (dashboard) reúne dos funciones sobre esas pruebas. La primera es automatizarlas, es decir, que el sistema conduzca su ejecución. La segunda es gestionarlas desde el panel. El panel es una aplicación web, hecha con Python y el framework Django.

### Qué se construyó

- Un panel (dashboard) web, hecho con Python y Django, para quienes se encargan de las pruebas de validación de la línea de producción.
- La automatización de las múltiples pruebas de validación de la línea, conducida desde el panel.
- La gestión de esas pruebas, hecha en el mismo panel.

### La tecnología, en palabras simples

- **Python**: lenguaje de programación de uso general, fácil de leer y muy usado en automatización, análisis de datos y sistemas web; en el proyecto, es el lenguaje en que se escribió el panel.
- **Django**: framework web escrito en Python, que ya trae partes comunes de un sistema web, como acceso a base de datos y área administrativa; fue la base del panel.
