### Para quién

El sitio se hizo para una agencia de publicidad multinacional y está dirigido a quien lo visita para conocer el estudio de caso de una inteligencia artificial que procesa mensajes de bullying recibidos por un perfil infantil simulado.

### Cómo funciona

El sitio es la plataforma del estudio de caso. Presenta la situación estudiada, un perfil infantil simulado que recibe mensajes de bullying, y la inteligencia artificial que procesa esos mensajes. La forma de presentarlo se pensó para ser llamativa, para que el caso capte la atención de quien llega al sitio.

### Qué se construyó

- El sitio del estudio de caso, la plataforma dedicada a presentarlo.
- La presentación del estudio de caso, pensada para ser llamativa, sobre la inteligencia artificial que procesa mensajes de bullying recibidos por un perfil infantil simulado.

### La tecnología, en palabras simples

- **Next.js**: framework basado en React para construir sitios y aplicaciones web. Con él se desarrolló el sitio del estudio de caso.
- **TypeScript**: lenguaje creado por Microsoft que agrega tipos a JavaScript, lo que ayuda a detectar errores en el código antes de que se ejecute. Formó parte del desarrollo del sitio.
- **React**: biblioteca de JavaScript para armar interfaces a partir de componentes reutilizables. También formó parte del desarrollo del sitio.
