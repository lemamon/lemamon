### Para quién

Para los sitios externos que incorporan el widget y para quienes los visitan y quieren ver la calidad del aire de una ciudad. El componente se desarrolló para una multinacional del comercio minorista.

### Cómo funciona

El widget es un acordeón: un bloque que se abre y se cierra dentro de la página del sitio que lo incorpora. Muestra la calidad del aire de la ciudad seleccionada por medio de gráficos dinámicos.

Los gráficos están conectados a una API de datos ambientales. Una API es la puerta por la que un sistema le entrega datos a otro. De esa API viene la información de calidad del aire de la ciudad seleccionada.

### Qué se construyó

- El componente en formato de acordeón, diseñado para incorporarse en sitios externos.
- Los gráficos dinámicos que muestran la calidad del aire de la ciudad seleccionada.
- La conexión de los gráficos con una API de datos ambientales, de donde viene la información.

### La tecnología, en palabras simples

- **React**: biblioteca de JavaScript para armar interfaces a partir de componentes reutilizables. Se empleó para construir el widget.
- **JavaScript**: el lenguaje de programación de la web, que le da comportamiento a las páginas en el navegador y también corre en servidores. También se empleó en el widget.
- **Chart.js**: biblioteca de JavaScript de código abierto para dibujar gráficos en páginas web. En el widget, es la tecnología de los gráficos de calidad del aire.
