### Para quién

El sistema fue concebido para un fabricante multinacional, para el proceso productivo que involucra placas electrónicas. Lo que busca proteger son esas placas: la finalidad del sistema es evitar que las descargas de energía estática las dañen durante la producción.

### Cómo funciona

La energía estática es la electricidad que se acumula en personas y objetos, y la descarga es el paso repentino de esa carga a otro objeto, como el pequeño choque eléctrico al tocar una manija. Las placas electrónicas son sensibles a estas descargas, que pueden dañarlas.

Al ser un sistema de detección de estática, la idea es detectar la estática para prevenir ese daño en el proceso productivo. Lo que el proyecto definió fue la estructura base del sistema, es decir, la base técnica del software, con Python y JavaScript.

### Qué se construyó

- La concepción de un sistema de detección de estática, pensado para evitar que las descargas dañen placas electrónicas en el proceso productivo.
- La estructura base del proyecto, definida con Python y JavaScript: la base técnica del software.

### La tecnología, en palabras simples

- **Python**: lenguaje de programación de uso general, fácil de leer y muy usado en automatización, análisis de datos y sistemas web; fue una de las dos tecnologías de la estructura base.
- **JavaScript**: el lenguaje de programación de la web, que le da comportamiento a las páginas en el navegador y también corre en servidores; fue la otra tecnología de la estructura base.
