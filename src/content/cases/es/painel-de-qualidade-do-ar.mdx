### Para quién

El panel se creó para una multinacional de la industria y es para quien quiere saber cómo está la calidad del aire.

### Cómo funciona

Una API es la puerta por la que un sistema le entrega datos a otro; aquí, la API de monitoreo provee las mediciones. Como la interfaz se conecta directamente a ella, lo que aparece en pantalla sigue esos datos.

### La tecnología, en palabras simples

- **HTML**: lenguaje que organiza el contenido de una página web, como textos, imágenes y botones. Se empleó en la interfaz del panel.
- **SCSS**: forma de escribir CSS, el lenguaje que define el aspecto de las páginas, con funciones extra como variables; se convierte en CSS común antes de llegar al navegador. Se empleó en la interfaz del panel.
- **JavaScript**: el lenguaje de programación de la web, que le da comportamiento a las páginas en el navegador y también corre en servidores. De las tres tecnologías del proyecto, es la que conecta el panel con la API de monitoreo del aire.
