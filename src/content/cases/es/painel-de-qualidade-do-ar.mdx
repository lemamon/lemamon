### Para quién

Para quien consulta el panel y quiere saber cómo está la calidad del aire. El panel informativo se creó para una multinacional de la industria, para mostrar esos índices en tiempo real.

### Cómo funciona

Una API de monitoreo del aire provee las mediciones. Una API es la puerta por la que un sistema le entrega datos a otro. La interfaz del panel se conecta directamente a esa API y muestra los índices de calidad del aire en tiempo real, es decir, lo que aparece en pantalla sigue los datos que la API provee.

### Qué se construyó

- La interfaz front-end del panel informativo, la parte que aparece en pantalla y muestra los índices de calidad del aire.
- La integración directa de la interfaz con una API de monitoreo del aire, de donde vienen los índices en tiempo real.

### La tecnología, en palabras simples

- **HTML**: lenguaje que organiza el contenido de una página web, como textos, imágenes y botones. Se empleó en la interfaz del panel.
- **SCSS**: forma de escribir CSS, el lenguaje que define el aspecto de las páginas, con funciones extra como variables; se convierte en CSS común antes de llegar al navegador. Se empleó en la interfaz del panel.
- **JavaScript**: el lenguaje de programación de la web, que le da comportamiento a las páginas en el navegador y también corre en servidores. De las tres tecnologías del proyecto, es la que conecta el panel con la API de monitoreo del aire.
