### Para quién

El sistema es para quien necesita comprar un pasaje de autobús. El pasajero puede hacer la compra en el navegador o en la app del celular.

### Cómo funciona

El sistema tiene tres partes. La aplicación web es el camino de compra en el navegador. La app móvil es el camino de compra en el celular. El servidor back-end es la parte que funciona tras bastidores del sistema, fuera de la vista del pasajero.

### Qué se construyó

- La aplicación web, para comprar pasajes de autobús en el navegador.
- La app móvil para Android, para comprar pasajes en el celular.
- El servidor back-end, la parte del sistema que funciona tras bastidores.

### La tecnología, en palabras simples

- **PHP**: lenguaje de programación hecho para funcionar en servidores y muy usado en sitios y sistemas web. Fue una de las tecnologías del proyecto.
- **Android**: sistema operativo de Google para celulares y tabletas. La app de compra de pasajes se hizo para él.
- **JavaScript**: el lenguaje de programación de la web, que le da comportamiento a las páginas en el navegador y también corre en servidores. Fue una de las tecnologías del proyecto.
