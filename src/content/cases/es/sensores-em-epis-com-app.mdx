### Para quién

El sistema se hizo para una gran empresa del sector energético y tiene que ver con los trabajadores que usan Equipos de Protección Personal (EPP) vestibles, el equipo de seguridad que llevan puesto mientras trabajan. Es el uso de esos equipos, por parte de esos trabajadores, lo que el sistema monitorea y valida.

### Cómo funciona

Los sensores están integrados a los propios EPP vestibles, es decir, van en el equipo que usa el trabajador. Esos sensores se conectan a una aplicación móvil. Con esa conexión entre los sensores del EPP y la aplicación, el sistema monitorea el uso de los equipos y valida que los trabajadores los usen de forma correcta.

### Qué se construyó

- Un conjunto de sensores integrados a los EPP vestibles, la parte del sistema que va en el propio equipo de protección.
- Una aplicación móvil, para Android, que se conecta a esos sensores y sirve para monitorear y validar el uso correcto de los EPP.

### La tecnología, en palabras simples

- **Node.js**: entorno que ejecuta JavaScript fuera del navegador, muy usado para crear servidores y APIs (las puertas por las que un sistema le entrega datos a otro).
- **Android**: sistema operativo de Google para celulares y tabletas; en el proyecto, es la plataforma de la aplicación móvil.
- **C**: lenguaje de programación de uso general, muy usado en software que corre cerca del hardware, como en aparatos electrónicos y sistemas embebidos.
