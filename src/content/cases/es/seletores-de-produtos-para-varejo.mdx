### Para quién

Para el usuario que necesita elegir, entre más de cien opciones, la que sirve para su caso. Las páginas forman parte de una iniciativa, fruto de una alianza entre dos multinacionales, una de ellas del comercio minorista, que reunió varios proyectos.

### Cómo funciona

En las páginas, el usuario cuenta con selectores de productos y de ambientes integrados. Estos guían la elección y ayudan al usuario a llegar, entre más de cien opciones, a la que sirve para su caso.

Además de los selectores, el trabajo tuvo otras piezas. Las plantillas son modelos reutilizables. El carrusel es un componente reutilizable: muestra elementos en secuencia y se puede usar más de una vez. El extractor convierte datos de hojas de cálculo XLSX a JSON, un formato de datos que las páginas web leen con facilidad.

### Qué se construyó

- Páginas con selectores de productos y de ambientes integrados, en los varios proyectos de la iniciativa.
- Plantillas, es decir, modelos reutilizables, creadas como parte del alcance.
- Un componente de carrusel reutilizable, un bloque que muestra elementos en secuencia y se puede aprovechar en más de un lugar.
- Un extractor de datos que convierte hojas de cálculo XLSX, el formato de archivo de Excel, a JSON.

### La tecnología, en palabras simples

- **JavaScript**: el lenguaje de programación de la web, que le da comportamiento a las páginas en el navegador y también corre en servidores.
- **Handlebars**: lenguaje de plantillas que genera HTML a partir de un modelo con espacios que se llenan con datos.
- **SCSS**: forma de escribir CSS, el lenguaje que define el aspecto de las páginas, con funciones extra como variables; se convierte en CSS común antes de llegar al navegador.
- **React**: biblioteca de JavaScript para armar interfaces a partir de componentes reutilizables.
- **HTML**: lenguaje que organiza el contenido de una página web, como textos, imágenes y botones.
- **Grunt**: herramienta que automatiza tareas repetitivas del desarrollo web, como convertir, unir y reducir archivos.
