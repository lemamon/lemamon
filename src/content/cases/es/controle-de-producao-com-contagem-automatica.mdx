### Para quién

El sistema se hizo para un fabricante y para quien controla su línea de producción.

### Cómo funciona

En la línea, la pequeña placa detecta cada artículo fabricado y lo contabiliza al instante. Ese conteo va al back-end, que está detrás del panel de métricas.

### La tecnología, en palabras simples

- **React**: biblioteca de JavaScript para armar interfaces a partir de componentes reutilizables; en el proyecto, la interfaz es el panel de métricas.
- **Prisma**: herramienta para Node.js y TypeScript que hace de puente entre el código del servidor y la base de datos.
- **GraphQL**: lenguaje de consulta para APIs, en el que quien pide los datos indica exactamente cuáles quiere recibir.
