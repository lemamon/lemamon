### Para quién

Para una multinacional de alimentos y bebidas y una de sus marcas, que necesitaba una plantilla para el sitio de la marca. Como los componentes están integrados con Sitecore, la plantilla también sirve a quien administra el contenido del sitio en ese CMS.

### Cómo funciona

La plantilla está formada por varios componentes modulares: piezas independientes que se combinan para armar las páginas del sitio. Cada componente cubre una parte de la página y se puede usar junto con los demás.

Esos componentes están integrados con Sitecore, el CMS del sitio. Un CMS es el sistema en el que se crea y se edita el contenido de un sitio sin tocar el código. Con la integración, los componentes funcionan junto con el sistema donde se gestiona el contenido de la marca.

### Qué se construyó

- Una plantilla para el sitio de la marca.
- Varios componentes modulares, las piezas que forman esa plantilla.
- La integración de los componentes con el CMS Sitecore.

### La tecnología, en palabras simples

- **JavaScript**: el lenguaje de programación de la web, que le da comportamiento a las páginas en el navegador y también corre en servidores. Se empleó para construir los componentes de la plantilla.
- **CSS**: lenguaje que define el aspecto de una página web, como colores, fuentes y espacios. Se empleó para construir los componentes.
- **HTML**: lenguaje que organiza el contenido de una página web, como textos, imágenes y botones. Se empleó para construir los componentes.
- **Sitecore**: sistema comercial de gestión de contenido (CMS) que las empresas usan para administrar sus sitios. Es el CMS con el que se integraron los componentes de la plantilla.
