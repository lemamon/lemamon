### Para quién

El sistema se diseñó para el equipo de calidad de una gran empresa de la industria. Ese equipo se encarga de los archivos de las auditorías de procesos, y el sistema existe para apoyarlo en la organización y gestión de esos archivos.

### Cómo funciona

Una auditoría de procesos verifica si un proceso se hace de la forma definida. Los archivos de esas auditorías son lo que el sistema ayuda a organizar y gestionar.

El equipo usa la interfaz del sistema (el front-end) para organizar y gestionar esos archivos. La interfaz se apoya en el back-end, la parte que corre en el servidor y responde a sus pedidos.

### Qué se construyó

- El front-end, la interfaz con la que el equipo de calidad organiza y gestiona los archivos de las auditorías de procesos.
- El back-end, la parte del sistema que corre en el servidor y sostiene la interfaz.

### La tecnología, en palabras simples

- **AngularJS**: framework de JavaScript para construir interfaces web que corren en el navegador; en el sistema, es la base del front-end.
- **JavaScript**: el lenguaje de programación de la web, que le da comportamiento a las páginas en el navegador y también corre en servidores; aquí, está en las dos partes del sistema.
- **LoopBack**: framework de Node.js para crear APIs, las puertas por las que la interfaz pide y recibe datos del servidor; en el sistema, es la base del back-end.
