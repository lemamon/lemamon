### Para quién

El sistema se diseñó para el equipo de calidad de una gran empresa de la industria.

### Cómo funciona

Una auditoría de procesos verifica si un proceso se hace de la forma definida.

El equipo trabaja en la interfaz. El back-end, detrás de ella, responde a los pedidos de la interfaz.

### La tecnología, en palabras simples

- **AngularJS**: framework de JavaScript para construir interfaces web que corren en el navegador; en el sistema, es la base del front-end.
- **JavaScript**: el lenguaje de programación de la web, que le da comportamiento a las páginas en el navegador y también corre en servidores; aquí, está en las dos partes del sistema.
- **LoopBack**: framework de Node.js para crear APIs, las puertas por las que la interfaz pide y recibe datos del servidor; en el sistema, es la base del back-end.
