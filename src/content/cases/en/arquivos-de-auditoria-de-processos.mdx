### Who it's for

The system was designed for the quality team of a large manufacturer.

### How it works

A process audit checks whether a process is carried out the way it was defined.

The team works in the interface. The back end, behind it, answers the interface's requests.

### The technology, in plain words

- **AngularJS**: a JavaScript framework for building web interfaces that run in the browser; in this system, it is the base of the front end.
- **JavaScript**: the programming language of the web, which gives pages behavior in the browser and also runs on servers; here, it is in both parts of the system.
- **LoopBack**: a Node.js framework for building APIs, the doorways through which the interface requests and receives data from the server; in this system, it is the base of the back end.
