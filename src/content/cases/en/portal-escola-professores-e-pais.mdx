### How it works

The web application is accessed in the browser, and the mobile app on the phone. The server runs behind both and keeps them on the same platform.

### The technology, in plain words

- **PHP**: a programming language made to run on servers and widely used in websites and web systems. It was one of the project's technologies.
- **PhoneGap**: an Adobe tool, based on Apache Cordova, for building mobile apps with web technologies (HTML, CSS and JavaScript). It was the basis of the system's mobile app.
- **JavaScript**: the programming language of the web, which gives pages behavior in the browser and also runs on servers. It is also the language of apps built with PhoneGap.
