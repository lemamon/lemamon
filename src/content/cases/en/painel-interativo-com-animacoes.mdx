### Who it is for

For the users of the client's interactive panel. The animations were designed for them: the idea is that they notice right on the home page that the panel is interactive, and that interacting with it feels intuitive.

### How it works

The animations implemented in the project are on the panel's home page. They make the interactivity more evident, so users notice they can interact with the panel, and more intuitive, so that interaction feels natural.

The animations are part of the update's main goal: improving the panel's look and the experience of the people who use it.

### What was built

- Animations on the panel's home page that make the interactivity more evident and intuitive for users.
- An update to the interactive panel's look and user experience, the project's main goal.

### The technology, in plain words

- **HTML**: the language that organizes the content of a web page, such as text, images and buttons. It was one of the technologies used for the home page animations.
- **CSS**: the language that defines how a web page looks, such as colors, fonts and spacing. It can also create animations, and it was used for the home page animations.
- **JavaScript**: the programming language of the web, which gives pages behavior in the browser and also runs on servers. It was also used for the home page animations.
