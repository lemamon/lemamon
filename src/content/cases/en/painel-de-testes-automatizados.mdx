### Who it is for

The dashboard was built for a multinational manufacturer and for the people who handle the validation tests on its production line: those responsible for automating and managing these tests.

### How it works

Multiple validation tests are run on the manufacturer's production line. The dashboard brings two functions to these tests. The first is automating them, that is, having the system carry out their execution. The second is managing them from the dashboard. The dashboard is a web application, built with Python and the Django framework.

### What was built

- A web dashboard, built with Python and Django, for the people who handle the production line's validation tests.
- Automation of the line's multiple validation tests, driven from the dashboard.
- Management of those tests, done in the same dashboard.

### The technology, in plain words

- **Python**: a general-purpose programming language, easy to read and widely used for automation, data analysis and web systems; in this project, it is the language the dashboard was written in.
- **Django**: a web framework written in Python that comes with common parts of a web system, such as database access and an admin area; it was the dashboard's base.
