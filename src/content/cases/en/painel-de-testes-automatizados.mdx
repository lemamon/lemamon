### Who it's for

The dashboard was built for a multinational manufacturer.

### How it works

Automating a test means having the system carry out its execution. It is in the dashboard, a web application, that the tests are automated and managed.

### The technology, in plain words

- **Python**: a general-purpose programming language, easy to read and widely used for automation, data analysis and web systems; in this project, it is the language the dashboard was written in.
- **Django**: a web framework written in Python that comes with common parts of a web system, such as database access and an admin area; it was the dashboard's base.
