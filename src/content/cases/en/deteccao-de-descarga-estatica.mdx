### Who it is for

The system was designed for a multinational manufacturer, for the production process that involves electronic boards. Those boards are what it aims to protect: the system's purpose is to keep static discharges from damaging them during production.

### How it works

Static electricity is charge that builds up on people and objects, and a discharge is that charge suddenly jumping to another object, like the small shock from touching a doorknob. Electronic boards are sensitive to these discharges, which can damage them.

Since this is a static detection system, the idea is to detect static in order to prevent that damage in the production process. What the project defined was the system's base structure, that is, the software's technical foundation, using Python and JavaScript.

### What was built

- The concept for a static detection system, meant to keep discharges from damaging electronic boards in the production process.
- The project's base structure, defined with Python and JavaScript: the software's technical foundation.

### The technology, in plain words

- **Python**: a general-purpose programming language, easy to read and widely used for automation, data analysis and web systems; it was one of the two technologies in the base structure.
- **JavaScript**: the programming language of the web, which gives pages behavior in the browser and also runs on servers; it was the other technology in the base structure.
