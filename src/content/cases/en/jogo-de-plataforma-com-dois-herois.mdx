### Who it is for

The game is for people who play on their phones: the player takes on two heroes at the same time, on a mission to save the world. It was developed within a multinational company's project.

### How it works

A platform game is the genre in which the character moves through settings with platforms and obstacles. Here, the game takes place in a post-apocalyptic world, and the player controls two heroes, each in a different setting. Both respond to the same on-screen buttons, so each tap applies to both heroes at once. The challenge is to guide both of them at the same time to save the world.

### What was built

- The mobile platform game, set in a post-apocalyptic world.
- The game's core mechanic: two heroes, in different settings, controlled at the same time by the same on-screen buttons.

### The technology, in plain words

- **Unity 3D**: a game engine, a tool for creating 2D and 3D games for phones, computers and consoles; it was the base for building the game.
- **C#**: a programming language from Microsoft, used to program games in Unity; the game's logic was written in it.
