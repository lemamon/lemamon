### Who it's for

The game is for people who play on their phones. It was developed within a multinational company's project.

### How it works

A platform game is the genre in which the character moves through settings with platforms and obstacles. Here, since both heroes respond to the same buttons, the challenge is to guide both at once, each in its own setting.

### The technology, in plain words

- **Unity 3D**: a game engine, a tool for creating 2D and 3D games for phones, computers and consoles; it was the base for building the game.
- **C#**: a programming language from Microsoft, used to program games in Unity; the game's logic was written in it.
