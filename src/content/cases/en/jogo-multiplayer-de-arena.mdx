### Who it is for

The game is for people who want to play on their phones with others connected to the same network, in multiplayer matches. It was part of an initiative of a multinational company.

### How it works

One player creates a local room. Other players connected to the same network join that room, and the match takes place among them. In the matches, the players take part in gladiator battles inside an arena.

### What was built

- The multiplayer mobile game, with gladiator battles in an arena.
- Local room creation, which brings players connected to the same network together in a match.

### The technology, in plain words

- **Unity 3D**: a game engine, a tool for creating 2D and 3D games for phones, computers and consoles; it was the base for developing the game.
- **C#**: a programming language from Microsoft, used to program games in Unity; the game's logic was written in it.
