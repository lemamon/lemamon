### Who it is for

The system was built for the quality assurance (QA) teams of a multinational manufacturer.

### How it works

Quality management is the set of processes and documents a company uses to look after quality. Audits are one part of that work, and that is where the system comes in.

QA teams work through the interface. The back end, behind it, handles what the interface requests.

### The technology, in plain words

- **AngularJS**: a JavaScript framework for building web interfaces that run in the browser; in this system, it is the base of the front end.
- **JavaScript**: the programming language of the web, which gives pages behavior in the browser and also runs on servers; in this system, it is in both parts of the application.
- **LoopBack**: a Node.js framework for building APIs, the doorways through which the interface requests and receives data from the server; in this system, it is the base of the back end.
