### Who it is for

The system was built for the quality assurance (QA) teams of a multinational manufacturer. They are the ones who need to manage documents and files during audit processes, and that is the work the system supports.

### How it works

Quality management is the set of processes and documents a company uses to look after quality. This quality management system supports one part of that work: the documents and files used during audits.

QA teams work through the interface, the front end, where they manage these documents and files. Behind it sits the back end, the part of the application that runs on the server and handles what the interface requests.

### What was built

- The system's front end, the interface QA teams use to manage documents and files during audits.
- The system's back end, the part of the application that runs on the server and supports the interface.

### The technology, in plain words

- **AngularJS**: a JavaScript framework for building web interfaces that run in the browser; in this system, it is the base of the front end.
- **JavaScript**: the programming language of the web, which gives pages behavior in the browser and also runs on servers; in this system, it is in both parts of the application.
- **LoopBack**: a Node.js framework for building APIs, the doorways through which the interface requests and receives data from the server; in this system, it is the base of the back end.
