### Who it is for

For people who check the dashboard to see how the air quality is. The information dashboard was created for a multinational manufacturing company, to display these indices in real time.

### How it works

An air monitoring API provides the measurements. An API is the doorway through which one system hands data to another. The dashboard interface connects directly to that API and displays air quality indices in real time, meaning what appears on screen keeps up with the data the API provides.

### What was built

- The information dashboard's front-end interface, the part that appears on screen and displays the air quality indices.
- The direct integration of the interface with an air monitoring API, where the real-time indices come from.

### The technology, in plain words

- **HTML**: the language that organizes the content of a web page, such as text, images and buttons. It was used in the dashboard interface.
- **SCSS**: a way of writing CSS, the language that defines how pages look, with extra features such as variables; it is turned into plain CSS before it reaches the browser. It was used in the dashboard interface.
- **JavaScript**: the programming language of the web, which gives pages behavior in the browser and also runs on servers. Of the project's three technologies, it is the one that connects the dashboard to the air monitoring API.
