### Who it's for

The app is for people who use wearable devices and want to follow their own health and wellness on their phones.

### How it works

First, the app connects to the wearables. Next, it collects biometric metrics from them, that is, body measurements captured by the devices. Finally, it uses them to build the health routine the user sees.

### The technology, in plain words

- **Ionic**: a framework, that is, a ready-made code base, for building mobile apps with web technologies such as HTML, CSS and JavaScript. The app was built with it.
- **TypeScript**: a language created by Microsoft that adds types to JavaScript, which helps catch errors in the code before it runs. It is the language the app was written in.
