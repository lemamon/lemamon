### Who it is for

The system was built for a manufacturer and for whoever controls its production line: the people who need to know how many items the line is making at that moment and to follow the industrial metrics the system records.

### How it works

On the production line, a small electronic board detects each manufactured item and counts it right away, in real time. That count goes to the back end, the part of the system that runs on the server. In the dashboard, industrial metrics are recorded and can be viewed by whoever controls the line.

### What was built

- Real-time detection and counting of manufactured items, done by a small electronic board on the production line.
- A structured back end, the part of the system that runs on the server and receives the count.
- A dashboard to record and view the line's industrial metrics.

### The technology, in plain words

- **React**: a JavaScript library for building interfaces from reusable components; in this project, the interface is the metrics dashboard.
- **Prisma**: a tool for Node.js and TypeScript that bridges server code and the database.
- **GraphQL**: a query language for APIs, where whoever requests data states exactly what it wants back.
