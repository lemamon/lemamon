### Who it is for

The pages are part of an initiative that came out of a partnership between two multinationals, one of them in retail, and brought together several projects.

### How it works

The product and space selectors are built into the pages and guide the choice.

The other pieces: the templates are reusable models; the carousel shows items in sequence and can be used more than once; the extractor converts data from XLSX spreadsheets, Excel's file format, to JSON, a data format web pages read easily.

### The technology, in plain words

- **JavaScript**: the programming language of the web, which gives pages behavior in the browser and also runs on servers.
- **Handlebars**: a templating language that generates HTML from a model with blanks that are filled in with data.
- **SCSS**: a way of writing CSS, the language that defines how pages look, with extra features such as variables; it is turned into plain CSS before it reaches the browser.
- **React**: a JavaScript library for building interfaces from reusable components.
- **HTML**: the language that organizes the content of a web page, such as text, images and buttons.
- **Grunt**: a tool that automates repetitive web development tasks, such as converting, combining and minifying files.
