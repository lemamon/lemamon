### Who it is for

For users who need to choose, among more than a hundred options, the one that fits their case. The pages are part of an initiative that came out of a partnership between two multinationals, one of them in retail, and brought together several projects.

### How it works

On the pages, users have integrated product and space selectors. They guide the choice and help users reach, among more than a hundred options, the one that fits their case.

Besides the selectors, the work had other pieces. The templates are reusable models. The carousel is a reusable component: it shows items in sequence and can be used more than once. The extractor converts XLSX spreadsheet data to JSON, a data format web pages read easily.

### What was built

- Pages with integrated product and space selectors, across the initiative's several projects.
- Templates, that is, reusable models, created as part of the scope.
- A reusable carousel component, a block that shows items in sequence and can be used in more than one place.
- A data extractor that converts XLSX spreadsheets, the Excel file format, to JSON.

### The technology, in plain words

- **JavaScript**: the programming language of the web, which gives pages behavior in the browser and also runs on servers.
- **Handlebars**: a templating language that generates HTML from a model with blanks that are filled in with data.
- **SCSS**: a way of writing CSS, the language that defines how pages look, with extra features such as variables; it is turned into plain CSS before it reaches the browser.
- **React**: a JavaScript library for building interfaces from reusable components.
- **HTML**: the language that organizes the content of a web page, such as text, images and buttons.
- **Grunt**: a tool that automates repetitive web development tasks, such as converting, combining and minifying files.
