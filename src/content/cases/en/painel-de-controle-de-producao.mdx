### Who it is for

The system was built for a manufacturer and for whoever controls its production. The dashboard is an admin dashboard, meaning it is meant for the people who manage data on manufactured products.

### How it works

The system has two parts that work together. In the admin dashboard, data on manufactured products is recorded and displayed. Behind it sits the dedicated back end, the part that runs on the server and serves only this system: it supports recording and displaying that data in the dashboard.

### What was built

- A dedicated back end, the part of the production control system that runs on the server.
- An admin dashboard to record and display data on manufactured products.

### The technology, in plain words

- **AngularJS**: a JavaScript framework for building web interfaces that run in the browser; in this project, it is the base of the admin dashboard.
- **JavaScript**: the programming language of the web, which gives pages behavior in the browser and also runs on servers; in this project, it is in both the dashboard and the back end.
- **LoopBack**: a Node.js framework for building APIs, the doorways through which the dashboard requests and receives data from the server; in this project, it is the base of the dedicated back end.
