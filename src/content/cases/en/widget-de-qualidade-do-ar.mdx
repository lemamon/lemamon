### Who it is for

For external websites that embed the widget, and for their visitors who want to see the air quality of a city. The component was developed for a multinational retailer.

### How it works

The widget is an accordion: a block that expands and collapses inside the page of the website that embeds it. It shows the selected city's air quality through dynamic charts.

The charts are connected to an environmental data API. An API is the doorway through which one system hands data to another. The air quality information for the selected city comes from that API.

### What was built

- The accordion component, designed to be embedded in external websites.
- The dynamic charts that show the selected city's air quality.
- The connection between the charts and an environmental data API, where the information comes from.

### The technology, in plain words

- **React**: a JavaScript library for building interfaces from reusable components. It was used to build the widget.
- **JavaScript**: the programming language of the web, which gives pages behavior in the browser and also runs on servers. It was also used in the widget.
- **Chart.js**: an open-source JavaScript library for drawing charts on web pages. In the widget, it is the technology behind the air quality charts.
