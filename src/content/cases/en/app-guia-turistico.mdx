### How it works

Visitors use the app on an Android phone. Because it is native, it was built with Android's own tools, not with web technologies adapted for the phone.

### The technology, in plain words

- **Android**: Google's operating system for phones and tablets. The app was built natively for it, that is, with Android's own tools.
