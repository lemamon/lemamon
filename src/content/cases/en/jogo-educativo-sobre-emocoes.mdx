### Who it's for

The game is made for children.

### How it works

Each player is a user of the game, managed in Firebase, and the actions and choices the child makes while playing are recorded there too.

### The technology, in plain words

- **Unity 3D**: a game engine, a tool for creating 2D and 3D games for phones, computers and consoles. The game was built in it.
- **C#**: a programming language from Microsoft, used to program games in Unity. In this project, it is the game's language.
- **Firebase**: a set of Google services that gives apps a ready-made server side, such as user accounts and databases. In this project, it handled user management and the record of actions and choices in the game.
