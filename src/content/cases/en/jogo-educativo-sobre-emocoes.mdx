### Who it is for

The game is made for children. It is an educational mobile game created to help them identify and understand their own emotions as they play.

### How it works

Children play the game on a phone. Each player is a user of the game, managed in Firebase. As the child plays, the actions and choices they make inside the game are recorded, also in Firebase.

### What was built

- The educational mobile game, about identifying and understanding one's own emotions.
- User management for the game, with Firebase.
- A record of each user's actions and choices inside the game, with Firebase.

### The technology, in plain words

- **Unity 3D**: a game engine, a tool for creating 2D and 3D games for phones, computers and consoles. The game was built in it.
- **C#**: a programming language from Microsoft, used to program games in Unity. In this project, it is the game's language.
- **Firebase**: a set of Google services that gives apps a ready-made server side, such as user accounts and databases. In this project, it handled user management and the record of actions and choices in the game.
