### Who it's for

The website was built for a multinational advertising agency and is aimed at people who want to learn about the case study.

### How it works

The website presents the situation studied, a simulated child profile that receives bullying messages, and the artificial intelligence that processes those messages.

### The technology, in plain words

- **Next.js**: a framework built on React for creating websites and web applications. It was used to develop the case study website.
- **TypeScript**: a language created by Microsoft that adds types to JavaScript, which helps catch errors in the code before it runs. It was used to develop the website.
- **React**: a JavaScript library for building interfaces from reusable components. It was also used on the website.
