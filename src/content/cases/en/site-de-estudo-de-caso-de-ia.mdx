### Who it is for

The website was built for a multinational advertising agency and is aimed at people who visit it to learn about the case study of an artificial intelligence that processes bullying messages received by a simulated child profile.

### How it works

The website is the case study's platform. It presents the situation studied, a simulated child profile that receives bullying messages, and the artificial intelligence that processes those messages. The presentation was designed to be striking, so the case catches the attention of anyone who arrives on the website.

### What was built

- The case study website, the platform dedicated to presenting it.
- The presentation of the case study, designed to be striking, about the artificial intelligence that processes bullying messages received by a simulated child profile.

### The technology, in plain words

- **Next.js**: a framework built on React for creating websites and web applications. It was used to develop the case study website.
- **TypeScript**: a language created by Microsoft that adds types to JavaScript, which helps catch errors in the code before it runs. It was used to develop the website.
- **React**: a JavaScript library for building interfaces from reusable components. It was also used on the website.
