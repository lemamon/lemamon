### Who it is for

For a multinational food and beverage company and one of its brands, which needed a template for the brand's website. Since the components are integrated with Sitecore, the template also serves the people who manage the site's content in that CMS.

### How it works

The template is made of several modular components: independent pieces that combine to build the website's pages. Each component handles one part of a page and can be used together with the others.

These components are integrated with Sitecore, the website's CMS. A CMS is the system used to create and edit a website's content without touching the code. With the integration, the components work together with the system where the brand's content is managed.

### What was built

- A template for the brand's website.
- Several modular components, the pieces that make up that template.
- The integration of the components with the Sitecore CMS.

### The technology, in plain words

- **JavaScript**: the programming language of the web, which gives pages behavior in the browser and also runs on servers. It was used to build the template's components.
- **CSS**: the language that defines how a web page looks, such as colors, fonts and spacing. It was used to build the components.
- **HTML**: the language that organizes the content of a web page, such as text, images and buttons. It was used to build the components.
- **Sitecore**: a commercial content management system (CMS) that companies use to run their websites. It is the CMS the template's components were integrated with.
