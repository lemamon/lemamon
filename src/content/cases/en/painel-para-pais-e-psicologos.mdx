### Who it is for

The dashboard is for parents and psychologists. It is where they access and analyze the data collected while children use an educational mobile game about emotions.

### How it works

While children interact with the mobile game, data from that interaction is collected. Parents and psychologists open the web dashboard in a browser and, there, access and analyze that data.

The dashboard and the institutional page are part of the project's ecosystem, alongside the game.

### What was built

- A web dashboard where parents and psychologists access and analyze the data collected while children interact with the game.
- An institutional page, part of the game project's ecosystem.

### The technology, in plain words

- **JavaScript**: the programming language of the web, which gives pages behavior in the browser and also runs on servers. It is the language of the dashboard and the page.
- **React**: a JavaScript library for building interfaces from reusable components. The dashboard and the page were built with it.
- **Firebase**: a set of Google services that gives apps a ready-made server side, such as user accounts and databases. It was also part of building the dashboard and the page.
