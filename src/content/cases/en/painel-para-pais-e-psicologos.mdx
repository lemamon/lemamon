### Who it is for

The dashboard is for parents and psychologists. The game the data comes from is an educational mobile game about emotions.

### How it works

While children play, data from that interaction is collected; the web dashboard, opened in a browser, is where parents and psychologists find it. The dashboard and the institutional page sit in the same ecosystem as the game.

### The technology, in plain words

- **JavaScript**: the programming language of the web, which gives pages behavior in the browser and also runs on servers. It is the language of the dashboard and the page.
- **React**: a JavaScript library for building interfaces from reusable components. The dashboard and the page were built with it.
- **Firebase**: a set of Google services that gives apps a ready-made server side, such as user accounts and databases. It was also part of building the dashboard and the page.
