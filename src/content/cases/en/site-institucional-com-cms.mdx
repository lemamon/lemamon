### Who it is for

The website serves the brand and its visitors. The content management system (CMS) serves whoever looks after the website's content.

### How it works

The content is kept in the CMS. Instead of storing the text in the page itself, the dynamic templates pull that content from the CMS and display it on the website. The homepage is the first page visitors see when they enter the official website.

### The technology, in plain words

- **PHP**: a programming language made to run on servers and widely used in websites and web systems; WordPress is written in it, and it was used in the project alongside WordPress.
- **WordPress**: an open-source content management system (CMS) used to create and manage websites; it was the base of the brand's CMS.
