### Para quem

O app foi feito para os consumidores que compram gás doméstico (GLP) e querem recebê-lo com entrega direta, e para a distribuidora, que tem nele o aplicativo principal da sua marca.

### Como funciona

GLP é o gás liquefeito de petróleo, o gás de cozinha usado nas casas. O app funciona como um marketplace, ou seja, um espaço de venda on-line que reúne quem vende e quem compra, voltado à comercialização desse gás. Pelo celular, o consumidor compra o gás e recebe a entrega direto.

O aplicativo foi feito em duas versões nativas, isto é, cada uma feita especificamente para o seu sistema: uma para Android e outra para iOS. Cada versão foi escrita na linguagem própria da sua plataforma.

### O que foi construído

- O aplicativo para Android, feito com Java e Kotlin.
- O aplicativo para iOS, feito com Swift.
- Nas duas versões, o marketplace de venda e entrega de gás doméstico (GLP) direto ao consumidor.

### Tecnologia, em linguagem simples

- **Android**: sistema operacional do Google para celulares e tablets; no projeto, uma das duas plataformas do app.
- **iOS**: sistema operacional da Apple para iPhone; no projeto, a outra plataforma do app.
- **Java**: linguagem de programação de uso geral, por muitos anos a principal linguagem para criar apps Android; no projeto, usada na versão Android.
- **Kotlin**: linguagem de programação compatível com Java, com suporte oficial do Google para criar apps Android; no projeto, usada na versão Android, junto com o Java.
- **Swift**: linguagem de programação criada pela Apple, usada em apps de iPhone e iPad; no projeto, é a linguagem da versão iOS.
