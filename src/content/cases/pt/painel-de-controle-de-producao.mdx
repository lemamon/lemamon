### Para quem

O sistema foi feito para uma fabricante e para quem controla a sua produção. O painel é administrativo, ou seja, voltado a quem administra os dados sobre os produtos fabricados.

### Como funciona

O sistema tem duas partes que trabalham juntas. No painel administrativo (dashboard), os dados sobre os produtos fabricados são registrados e exibidos. Por trás dele fica o back-end dedicado, a parte que roda no servidor e atende só a esse sistema: é ele que dá suporte ao registro e à exibição desses dados no painel.

### O que foi construído

- Um back-end dedicado, a parte do sistema de controle de produção que roda no servidor.
- Um painel administrativo (dashboard) para registrar e exibir dados sobre os produtos fabricados.

### Tecnologia, em linguagem simples

- **AngularJS**: framework JavaScript para construir interfaces web que rodam no navegador; no projeto, é a base do painel administrativo.
- **JavaScript**: linguagem de programação da web, que dá comportamento às páginas no navegador e também roda em servidores; no projeto, está no painel e no back-end.
- **LoopBack**: framework de Node.js para criar APIs, as portas pelas quais o painel pede e recebe dados do servidor; no projeto, é a base do back-end dedicado.
