### Para quem

O sistema foi feito para uma fabricante e para quem controla a sua linha de produção: quem precisa saber quantos itens a linha está fabricando naquele momento e acompanhar as métricas industriais que o sistema registra.

### Como funciona

Na linha de produção, uma microplaca (uma pequena placa eletrônica) detecta cada item fabricado e o contabiliza na hora, em tempo real. Essa contagem segue para o back-end, a parte do sistema que roda no servidor. No painel (dashboard), as métricas industriais ficam registradas e podem ser visualizadas por quem controla a linha.

### O que foi construído

- A detecção e a contagem dos itens fabricados em tempo real, feitas por uma microplaca na linha de produção.
- Um back-end estruturado, a parte do sistema que roda no servidor e recebe a contagem.
- Um painel (dashboard) para registrar e visualizar as métricas industriais da linha.

### Tecnologia, em linguagem simples

- **React**: biblioteca JavaScript para montar interfaces a partir de componentes reutilizáveis; no projeto, a interface é o painel de métricas.
- **Prisma**: ferramenta para Node.js e TypeScript que faz a ponte entre o código do servidor e o banco de dados.
- **GraphQL**: linguagem de consulta para APIs, em que quem pede os dados diz exatamente quais quer receber.
