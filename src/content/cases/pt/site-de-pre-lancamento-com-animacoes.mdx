### Para quem

O site foi feito para uma marca de alimentos, na fase de pré-lançamento, e para quem visitasse a página nesse período.

### Como funciona

Na técnica de sprites, o código mostra os quadros de imagem de um movimento um de cada vez, em sequência; a troca rápida entre eles cria a ilusão de animação.

### Tecnologia, em linguagem simples

- **HTML**: linguagem que organiza o conteúdo de uma página web, como textos, imagens e botões; é a base do site.
- **JavaScript**: linguagem de programação da web, que dá comportamento às páginas no navegador e também roda em servidores; foi usada com o HTML para construir o site e as suas animações interativas.
