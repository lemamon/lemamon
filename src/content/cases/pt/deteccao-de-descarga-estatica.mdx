### Para quem

O sistema foi concebido para uma fabricante multinacional, para o processo produtivo que envolve placas eletrônicas. O alvo da proteção são essas placas: a finalidade do sistema é evitar que descargas de energia estática as danifiquem durante a produção.

### Como funciona

Energia estática é a eletricidade que se acumula em pessoas e objetos, e a descarga é a passagem repentina dessa carga para outro objeto, como o pequeno choque ao tocar uma maçaneta. Placas eletrônicas são sensíveis a essas descargas, que podem danificá-las.

Por ser um sistema de detecção de estática, a proposta é detectar a estática para prevenir esse dano no processo produtivo. O que o projeto definiu foi a estrutura base do sistema, isto é, a base técnica do software, com Python e JavaScript.

### O que foi construído

- A concepção de um sistema de detecção de estática, com a finalidade de evitar que descargas danifiquem placas eletrônicas no processo produtivo.
- A estrutura base do projeto, definida com Python e JavaScript: a base técnica do software.

### Tecnologia, em linguagem simples

- **Python**: linguagem de programação de uso geral, de leitura simples, muito usada em automação, análise de dados e sistemas web; foi uma das duas tecnologias da estrutura base.
- **JavaScript**: linguagem de programação da web, que dá comportamento às páginas no navegador e também roda em servidores; foi a outra tecnologia da estrutura base.
