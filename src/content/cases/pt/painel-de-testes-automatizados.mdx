### Para quem

O painel foi feito para uma fabricante multinacional e para quem cuida dos testes de validação da sua linha de produção: as pessoas responsáveis por automatizar e gerenciar esses testes.

### Como funciona

Na linha de produção da fabricante são feitos múltiplos testes de validação. O painel (dashboard) reúne duas funções sobre esses testes. A primeira é automatizá-los, isto é, fazer o sistema conduzir a sua execução. A segunda é gerenciá-los a partir do painel. O painel é uma aplicação web, feita com Python e o framework Django.

### O que foi construído

- Um painel (dashboard) web, feito com Python e Django, para quem cuida dos testes de validação da linha de produção.
- A automação dos múltiplos testes de validação da linha, conduzida a partir do painel.
- A gestão desses testes, feita no mesmo painel.

### Tecnologia, em linguagem simples

- **Python**: linguagem de programação de uso geral, de leitura simples, muito usada em automação, análise de dados e sistemas web; no projeto, é a linguagem em que o painel foi escrito.
- **Django**: framework web escrito em Python, que já traz partes comuns de um sistema web, como acesso a banco de dados e área administrativa; foi a base do painel.
