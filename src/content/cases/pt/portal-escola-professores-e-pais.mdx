### Para quem

O sistema atende três públicos de uma escola: a administração, os professores e os pais de alunos. Ele foi feito para aproximar e conectar esses três grupos.

### Como funciona

O sistema de gestão escolar reúne a administração, os professores e os pais de alunos em um só lugar. A plataforma integra três partes: a aplicação web, acessada pelo navegador; o aplicativo móvel, usado no celular; e o servidor, que roda por trás das duas.

### O que foi construído

- A aplicação web do sistema de gestão escolar, acessada pelo navegador.
- O aplicativo móvel, feito com PhoneGap.
- O servidor, a parte que roda por trás da aplicação web e do aplicativo.

### Tecnologia, em linguagem simples

- **PHP**: linguagem de programação feita para rodar em servidores e muito usada em sites e sistemas web. Foi uma das tecnologias do projeto.
- **PhoneGap**: ferramenta da Adobe, baseada no Apache Cordova, para criar apps móveis com tecnologias da web (HTML, CSS e JavaScript). Foi a base do aplicativo móvel do sistema.
- **JavaScript**: linguagem de programação da web, que dá comportamento às páginas no navegador e também roda em servidores. É também a linguagem dos apps feitos com PhoneGap.
