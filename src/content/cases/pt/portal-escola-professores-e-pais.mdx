### Como funciona

A aplicação web é acessada pelo navegador, e o aplicativo móvel, pelo celular. O servidor roda por trás das duas e as mantém na mesma plataforma.

### Tecnologia, em linguagem simples

- **PHP**: linguagem de programação feita para rodar em servidores e muito usada em sites e sistemas web. Foi uma das tecnologias do projeto.
- **PhoneGap**: ferramenta da Adobe, baseada no Apache Cordova, para criar apps móveis com tecnologias da web (HTML, CSS e JavaScript). Foi a base do aplicativo móvel do sistema.
- **JavaScript**: linguagem de programação da web, que dá comportamento às páginas no navegador e também roda em servidores. É também a linguagem dos apps feitos com PhoneGap.
