### Para quem

Para quem consulta o painel e quer saber como está a qualidade do ar. O painel informativo foi criado para uma multinacional da indústria, para exibir esses índices em tempo real.

### Como funciona

Uma API de monitoramento do ar fornece as medições. API é a porta pela qual um sistema entrega dados a outro. A interface do painel se conecta direto a essa API e exibe os índices de qualidade do ar em tempo real, ou seja, o que aparece na tela acompanha os dados que a API fornece.

### O que foi construído

- A interface front-end do painel informativo, a parte que aparece na tela e exibe os índices de qualidade do ar.
- A integração direta da interface com uma API de monitoramento do ar, de onde vêm os índices em tempo real.

### Tecnologia, em linguagem simples

- **HTML**: linguagem que organiza o conteúdo de uma página web, como textos, imagens e botões. Foi usado na interface do painel.
- **SCSS**: forma de escrever CSS, a linguagem que define a aparência das páginas, com recursos extras como variáveis; vira CSS comum antes de ir para o navegador. Foi usado na interface do painel.
- **JavaScript**: linguagem de programação da web, que dá comportamento às páginas no navegador e também roda em servidores. Entre as três tecnologias do projeto, é a que liga o painel à API de monitoramento do ar.
