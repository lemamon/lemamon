### Para quem

O jogo é para quem joga no celular. Ele foi desenvolvido no âmbito de um projeto de uma multinacional.

### Como funciona

Jogo de plataforma é o gênero em que o personagem avança por cenários com plataformas e obstáculos. Aqui, como os dois heróis respondem aos mesmos botões, o desafio é guiar os dois de uma vez, cada um no seu cenário.

### Tecnologia, em linguagem simples

- **Unity 3D**: motor de jogos, uma ferramenta para criar jogos em 2D e 3D para celular, computador e console; foi a base da construção do jogo.
- **C#**: linguagem de programação da Microsoft, usada para programar jogos no Unity; nela foi escrita a lógica do jogo.
