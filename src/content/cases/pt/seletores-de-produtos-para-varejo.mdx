### Para quem

As páginas fazem parte de uma iniciativa, fruto de uma parceria entre duas multinacionais, uma delas do varejo, que reuniu vários projetos.

### Como funciona

Os seletores de produtos e de ambientes ficam integrados às páginas e guiam a escolha.

As outras peças: os templates são modelos reaproveitáveis; o carrossel exibe itens em sequência e pode ser usado mais de uma vez; o extrator converte dados de planilhas XLSX, o formato de arquivo do Excel, em JSON, um formato de dados que páginas web leem com facilidade.

### Tecnologia, em linguagem simples

- **JavaScript**: linguagem de programação da web, que dá comportamento às páginas no navegador e também roda em servidores.
- **Handlebars**: linguagem de templates que gera HTML a partir de um modelo com espaços que são preenchidos com dados.
- **SCSS**: forma de escrever CSS, a linguagem que define a aparência das páginas, com recursos extras como variáveis; vira CSS comum antes de ir para o navegador.
- **React**: biblioteca JavaScript para montar interfaces a partir de componentes reutilizáveis.
- **HTML**: linguagem que organiza o conteúdo de uma página web, como textos, imagens e botões.
- **Grunt**: ferramenta que automatiza tarefas repetitivas do desenvolvimento web, como converter, juntar e reduzir arquivos.
