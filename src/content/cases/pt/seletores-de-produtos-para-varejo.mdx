### Para quem

Para o usuário que precisa escolher, entre mais de cem opções, a que serve para o seu caso. As páginas fazem parte de uma iniciativa, fruto de uma parceria entre duas multinacionais, uma delas do varejo, que reuniu vários projetos.

### Como funciona

Nas páginas, o usuário conta com seletores de produtos e de ambientes integrados. Eles guiam a escolha e ajudam o usuário a chegar, entre mais de cem opções, à que serve para o seu caso.

Além dos seletores, o trabalho teve outras peças. Os templates são modelos reaproveitáveis. O carrossel é um componente reutilizável: exibe itens em sequência e pode ser usado mais de uma vez. O extrator converte dados de planilhas XLSX em JSON, um formato de dados que páginas web leem com facilidade.

### O que foi construído

- Páginas com seletores de produtos e de ambientes integrados, nos vários projetos da iniciativa.
- Templates, ou seja, modelos reaproveitáveis, criados como parte do escopo.
- Um componente de carrossel reutilizável, um bloco que exibe itens em sequência e pode ser aproveitado em mais de um lugar.
- Um extrator de dados que converte planilhas XLSX, o formato de arquivo do Excel, em JSON.

### Tecnologia, em linguagem simples

- **JavaScript**: linguagem de programação da web, que dá comportamento às páginas no navegador e também roda em servidores.
- **Handlebars**: linguagem de templates que gera HTML a partir de um modelo com espaços que são preenchidos com dados.
- **SCSS**: forma de escrever CSS, a linguagem que define a aparência das páginas, com recursos extras como variáveis; vira CSS comum antes de ir para o navegador.
- **React**: biblioteca JavaScript para montar interfaces a partir de componentes reutilizáveis.
- **HTML**: linguagem que organiza o conteúdo de uma página web, como textos, imagens e botões.
- **Grunt**: ferramenta que automatiza tarefas repetitivas do desenvolvimento web, como converter, juntar e reduzir arquivos.
