### Para quem

O jogo é para quem quer jogar no celular com outras pessoas conectadas à mesma rede, em partidas multiplayer. Ele fez parte de uma iniciativa de uma multinacional.

### Como funciona

Um jogador cria uma sala local. Outros jogadores conectados à mesma rede entram nessa sala, e a partida acontece entre eles. Nas partidas, os jogadores participam de batalhas de gladiadores dentro de uma arena.

### O que foi construído

- O jogo mobile multiplayer, com batalhas de gladiadores em uma arena.
- A criação de salas locais, que reúnem em uma partida os jogadores conectados à mesma rede.

### Tecnologia, em linguagem simples

- **Unity 3D**: motor de jogos, uma ferramenta para criar jogos em 2D e 3D para celular, computador e console; foi a base do desenvolvimento do jogo.
- **C#**: linguagem de programação da Microsoft, usada para programar jogos no Unity; nela foi escrita a lógica do jogo.
