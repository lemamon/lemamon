### Para quem

Para uma multinacional de alimentos e bebidas e uma de suas marcas, que precisava de um template para o site da marca. Como os componentes estão integrados ao Sitecore, o template também atende quem administra o conteúdo do site nesse CMS.

### Como funciona

O template é formado por diversos componentes modulares: peças independentes que se combinam para montar as páginas do site. Cada componente cumpre uma parte da página e pode ser usado junto com os outros.

Esses componentes estão integrados ao Sitecore, o CMS do site. Um CMS é o sistema em que se cria e se edita o conteúdo de um site sem mexer no código. Com a integração, os componentes funcionam junto com o sistema em que o conteúdo da marca é gerenciado.

### O que foi construído

- Um template para o site da marca.
- Diversos componentes modulares, as peças que formam esse template.
- A integração dos componentes com o CMS Sitecore.

### Tecnologia, em linguagem simples

- **JavaScript**: linguagem de programação da web, que dá comportamento às páginas no navegador e também roda em servidores. Foi usado na construção dos componentes do template.
- **CSS**: linguagem que define a aparência de uma página web, como cores, fontes e espaçamentos. Foi usado na construção dos componentes.
- **HTML**: linguagem que organiza o conteúdo de uma página web, como textos, imagens e botões. Foi usado na construção dos componentes.
- **Sitecore**: sistema comercial de gestão de conteúdo (CMS) usado por empresas para administrar seus sites. É o CMS ao qual os componentes do template foram integrados.
