### Para quem

O painel é para pais e psicólogos. É nele que eles acessam e analisam os dados coletados enquanto as crianças usam um jogo educativo para celular, sobre emoções.

### Como funciona

Enquanto as crianças interagem com o jogo mobile, dados dessa interação são coletados. Pais e psicólogos abrem o painel web no navegador e, ali, acessam e analisam esses dados.

O painel e a página institucional fazem parte do ecossistema do projeto, ao lado do jogo.

### O que foi construído

- Um painel web em que pais e psicólogos acessam e analisam os dados coletados durante a interação das crianças com o jogo.
- Uma página institucional, parte do ecossistema do projeto do jogo.

### Tecnologia, em linguagem simples

- **JavaScript**: linguagem de programação da web, que dá comportamento às páginas no navegador e também roda em servidores. É a linguagem do painel e da página.
- **React**: biblioteca JavaScript para montar interfaces a partir de componentes reutilizáveis. O painel e a página foram desenvolvidos com ela.
- **Firebase**: conjunto de serviços do Google que dá aos apps uma parte de servidor pronta, como contas de usuário e banco de dados. Também fez parte do desenvolvimento do painel e da página.
