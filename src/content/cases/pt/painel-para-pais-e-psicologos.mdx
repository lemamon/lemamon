### Para quem

O painel é para pais e psicólogos. O jogo de onde vêm os dados é um jogo educativo para celular, sobre emoções.

### Como funciona

Enquanto as crianças jogam, dados dessa interação são coletados; o painel web, aberto no navegador, é onde pais e psicólogos os encontram. O painel e a página institucional ficam no mesmo ecossistema do jogo.

### Tecnologia, em linguagem simples

- **JavaScript**: linguagem de programação da web, que dá comportamento às páginas no navegador e também roda em servidores. É a linguagem do painel e da página.
- **React**: biblioteca JavaScript para montar interfaces a partir de componentes reutilizáveis. O painel e a página foram desenvolvidos com ela.
- **Firebase**: conjunto de serviços do Google que dá aos apps uma parte de servidor pronta, como contas de usuário e banco de dados. Também fez parte do desenvolvimento do painel e da página.
