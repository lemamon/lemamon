### Para quem

O sistema foi feito para uma grande empresa do setor de energia e diz respeito aos trabalhadores que usam Equipamentos de Proteção Individual (EPIs) vestíveis, os itens de segurança que eles levam no corpo durante o trabalho. É o uso desses equipamentos, por esses trabalhadores, que o sistema monitora e valida.

### Como funciona

Os sensores ficam integrados aos próprios EPIs vestíveis, ou seja, vão no equipamento que o trabalhador usa. Esses sensores se conectam a um aplicativo móvel. É com essa ligação entre os sensores no EPI e o aplicativo que o sistema monitora o uso dos equipamentos e valida se os trabalhadores os usam da forma correta.

### O que foi construído

- Um conjunto de sensores integrados aos EPIs vestíveis, a parte do sistema que fica no próprio equipamento de proteção.
- Um aplicativo móvel, para Android, que se conecta a esses sensores e serve para monitorar e validar o uso correto dos EPIs.

### Tecnologia, em linguagem simples

- **Node.js**: ambiente que executa JavaScript fora do navegador, muito usado para criar servidores e APIs (as portas pelas quais um sistema entrega dados a outro).
- **Android**: sistema operacional do Google para celulares e tablets; no projeto, é a plataforma do aplicativo móvel.
- **C**: linguagem de programação de uso geral, muito usada em software que roda perto do hardware, como em aparelhos eletrônicos e sistemas embarcados.
