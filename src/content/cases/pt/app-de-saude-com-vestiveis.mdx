### Para quem

O app é para quem usa dispositivos vestíveis e quer acompanhar a própria saúde e bem-estar pelo celular.

### Como funciona

Primeiro, o app se conecta aos vestíveis. Depois, coleta deles as métricas biométricas, isto é, medidas do corpo captadas pelos aparelhos. Por fim, monta com elas a rotina de saúde que o usuário vê.

### Tecnologia, em linguagem simples

- **Ionic**: framework, isto é, uma base pronta de código, para criar apps móveis com tecnologias da web, como HTML, CSS e JavaScript. O app foi construído com ele.
- **TypeScript**: linguagem criada pela Microsoft que acrescenta tipos ao JavaScript, o que ajuda a encontrar erros no código antes de ele rodar. É a linguagem em que o app foi escrito.
