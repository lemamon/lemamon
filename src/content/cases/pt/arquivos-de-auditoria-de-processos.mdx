### Para quem

O sistema foi projetado para a equipe de qualidade de uma grande empresa da indústria.

### Como funciona

Uma auditoria de processos verifica se um processo é feito da forma definida.

A equipe trabalha na interface. O back-end, por trás dela, responde aos pedidos da interface.

### Tecnologia, em linguagem simples

- **AngularJS**: framework JavaScript para construir interfaces web que rodam no navegador; no sistema, é a base do front-end.
- **JavaScript**: linguagem de programação da web, que dá comportamento às páginas no navegador e também roda em servidores; aqui, está nas duas partes do sistema.
- **LoopBack**: framework de Node.js para criar APIs, as portas pelas quais a interface pede e recebe dados do servidor; no sistema, é a base do back-end.
