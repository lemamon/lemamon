### Para quem

O sistema foi projetado para a equipe de qualidade de uma grande empresa da indústria. É ela que cuida dos arquivos referentes às auditorias de processos, e o sistema existe para apoiá-la na organização e na gestão desses arquivos.

### Como funciona

Uma auditoria de processos verifica se um processo é feito da forma definida. Os arquivos referentes a essas auditorias são o que o sistema ajuda a organizar e gerir.

A equipe usa a interface do sistema (o front-end) para organizar e gerir esses arquivos. A interface conta com o back-end, a parte que roda no servidor e responde aos pedidos dela.

### O que foi construído

- O front-end, a interface pela qual a equipe de qualidade organiza e gere os arquivos das auditorias de processos.
- O back-end, a parte do sistema que roda no servidor e sustenta a interface.

### Tecnologia, em linguagem simples

- **AngularJS**: framework JavaScript para construir interfaces web que rodam no navegador; no sistema, é a base do front-end.
- **JavaScript**: linguagem de programação da web, que dá comportamento às páginas no navegador e também roda em servidores; aqui, está nas duas partes do sistema.
- **LoopBack**: framework de Node.js para criar APIs, as portas pelas quais a interface pede e recebe dados do servidor; no sistema, é a base do back-end.
