### Para quem

O site foi feito para uma agência de publicidade multinacional e se dirige a quem o visita para conhecer o estudo de caso de uma inteligência artificial que processa mensagens de bullying recebidas por um perfil infantil simulado.

### Como funciona

O site é a plataforma do estudo de caso. Ele apresenta a situação estudada, um perfil infantil simulado que recebe mensagens de bullying, e a inteligência artificial que processa essas mensagens. A forma de apresentar foi pensada para ser marcante, para que o caso chame a atenção de quem chega ao site.

### O que foi construído

- O site do estudo de caso, a plataforma dedicada a apresentá-lo.
- A apresentação do estudo de caso, pensada para ser marcante, sobre a inteligência artificial que processa mensagens de bullying recebidas por um perfil infantil simulado.

### Tecnologia, em linguagem simples

- **Next.js**: framework baseado em React para construir sites e aplicações web. Foi usado no desenvolvimento do site do estudo de caso.
- **TypeScript**: linguagem criada pela Microsoft que acrescenta tipos ao JavaScript, o que ajuda a encontrar erros no código antes de ele rodar. Foi usada no desenvolvimento do site.
- **React**: biblioteca JavaScript para montar interfaces a partir de componentes reutilizáveis. Também foi usada no site.
