### Para quem

O jogo é feito para crianças. É um jogo educativo para celular, criado para ajudá-las a identificar e compreender as próprias emoções enquanto jogam.

### Como funciona

A criança joga no celular. Cada jogador é um usuário do jogo, gerenciado no Firebase. Enquanto a criança joga, as ações e escolhas que ela faz dentro do jogo são registradas, também no Firebase.

### O que foi construído

- O jogo mobile educativo, sobre identificar e compreender as próprias emoções.
- O gerenciamento dos usuários do jogo, com Firebase.
- O registro das ações e escolhas de cada usuário dentro do jogo, com Firebase.

### Tecnologia, em linguagem simples

- **Unity 3D**: motor de jogos, uma ferramenta para criar jogos em 2D e 3D para celular, computador e console. O jogo foi construído nele.
- **C#**: linguagem de programação da Microsoft, usada para programar jogos no Unity. No projeto, é a linguagem do jogo.
- **Firebase**: conjunto de serviços do Google que dá aos apps uma parte de servidor pronta, como contas de usuário e banco de dados. No projeto, cuidou do gerenciamento de usuários e do registro das ações e escolhas no jogo.
