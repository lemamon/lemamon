### Para quem

O sistema é para quem precisa comprar passagem de ônibus. O passageiro pode fazer a compra no navegador ou no aplicativo do celular.

### Como funciona

O sistema tem três partes. A aplicação web é o caminho de compra pelo navegador. O aplicativo móvel é o caminho de compra pelo celular. O servidor back-end é a parte que roda nos bastidores do sistema, fora da vista do passageiro.

### O que foi construído

- A aplicação web, para comprar passagens de ônibus pelo navegador.
- O aplicativo móvel para Android, para comprar passagens pelo celular.
- O servidor back-end, a parte do sistema que roda nos bastidores.

### Tecnologia, em linguagem simples

- **PHP**: linguagem de programação feita para rodar em servidores e muito usada em sites e sistemas web. Foi uma das tecnologias do projeto.
- **Android**: sistema operacional do Google para celulares e tablets. O aplicativo de compra de passagens foi feito para ele.
- **JavaScript**: linguagem de programação da web, que dá comportamento às páginas no navegador e também roda em servidores. Foi uma das tecnologias do projeto.
