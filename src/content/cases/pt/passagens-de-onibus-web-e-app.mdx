### Como funciona

Web e app são as duas portas de compra. O servidor back-end roda nos bastidores, fora da vista do passageiro.

### Tecnologia, em linguagem simples

- **PHP**: linguagem de programação feita para rodar em servidores e muito usada em sites e sistemas web. Foi uma das tecnologias do projeto.
- **Android**: sistema operacional do Google para celulares e tablets. O aplicativo de compra de passagens foi feito para ele.
- **JavaScript**: linguagem de programação da web, que dá comportamento às páginas no navegador e também roda em servidores. Foi uma das tecnologias do projeto.
