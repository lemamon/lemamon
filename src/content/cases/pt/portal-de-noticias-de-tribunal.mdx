### Para quem

O projeto foi feito para um tribunal, um órgão do Judiciário. A página inicial é a entrada do portal e atende quem o visita; a reformulação também olhou para quem cuida das notícias institucionais.

### Tecnologia, em linguagem simples

- **PHP**: linguagem de programação feita para rodar em servidores e muito usada em sites e sistemas web; foi usada na construção da nova página inicial.
- **HTML**: linguagem que organiza o conteúdo de uma página web, como textos, imagens e botões; é a base da estrutura da nova página inicial.
- **CSS**: linguagem que define a aparência de uma página web, como cores, fontes e espaçamentos; foi usada na parte visual da reformulação.
