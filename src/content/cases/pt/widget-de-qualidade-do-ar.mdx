### Para quem

Para sites externos que incorporam o widget e para quem os visita e quer ver a qualidade do ar de uma cidade. O componente foi desenvolvido para uma multinacional de varejo.

### Como funciona

O widget é um acordeão: um bloco que abre e fecha dentro da página do site que o incorpora. Ele mostra a qualidade do ar da cidade selecionada por meio de gráficos dinâmicos.

Os gráficos estão conectados a uma API de dados ambientais. API é a porta pela qual um sistema entrega dados a outro. É dessa API que vêm as informações de qualidade do ar da cidade selecionada.

### O que foi construído

- O componente em formato de acordeão, projetado para ser incorporado em sites externos.
- Os gráficos dinâmicos que mostram a qualidade do ar da cidade selecionada.
- A conexão dos gráficos com uma API de dados ambientais, de onde vêm as informações.

### Tecnologia, em linguagem simples

- **React**: biblioteca JavaScript para montar interfaces a partir de componentes reutilizáveis. Foi usado na construção do widget.
- **JavaScript**: linguagem de programação da web, que dá comportamento às páginas no navegador e também roda em servidores. Também foi usado no widget.
- **Chart.js**: biblioteca JavaScript de código aberto para desenhar gráficos em páginas web. No widget, é a tecnologia dos gráficos de qualidade do ar.
