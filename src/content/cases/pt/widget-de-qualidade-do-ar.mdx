### Para quem

Para sites externos que incorporam o widget e para quem os visita. O componente foi desenvolvido para uma multinacional de varejo.

### Como funciona

O acordeão abre e fecha dentro da página do site que o incorpora.

API é a porta pela qual um sistema entrega dados a outro: é da API de dados ambientais que vêm as informações que os gráficos mostram.

### Tecnologia, em linguagem simples

- **React**: biblioteca JavaScript para montar interfaces a partir de componentes reutilizáveis. Foi usado na construção do widget.
- **JavaScript**: linguagem de programação da web, que dá comportamento às páginas no navegador e também roda em servidores. Também foi usado no widget.
- **Chart.js**: biblioteca JavaScript de código aberto para desenhar gráficos em páginas web. No widget, é a tecnologia dos gráficos de qualidade do ar.
