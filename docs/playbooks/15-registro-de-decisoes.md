# 15 — Registro de decisões e de verificações

Vários itens do backlog têm como critério de aceite "decisão registrada". Este é o lugar. A recomendação de cada linha vem dos playbooks e das fontes citadas; **a decisão é sua**: preencha a coluna "Decisão", a data e quando reavaliar. Uma decisão que muda o que o site afirma também precisa ir para o BLUEPRINT (integrador) ou para um config.
